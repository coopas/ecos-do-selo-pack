# Ecos do Selo — Plano 1: Fundação — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Um pack packwiz Forge 1.20.1 com todos os mods do design, configs base, servidor portátil que sobe limpo, instância do Prism que abre até o menu, e um dump de registro (itens, tags, fluidos, entidades) que os próximos planos usam para validar quests e receitas.

**Architecture:** A fonte do pack fica em `C:\modpack-svers\pack\` (packwiz). Uma pasta `tools/` com scripts Python (testados com pytest) monta o servidor em `build/server/`, a instância do Prism em `build/prism/`, roda os testes de boot e lê o dump de registro gerado por um script KubeJS só de desenvolvimento.

**Tech Stack:** packwiz (via `go install`), packwiz-installer-bootstrap, Forge 1.20.1-47.x, Java 17 (`%APPDATA%\PrismLauncher\java\java-runtime-gamma\bin\java.exe`), Python 3.12 + pytest, KubeJS 6 (Forge), git, gh (conta `coopas` já logada).

**Spec:** `docs/2026-11-03-ecos-do-selo-design.md`

**Roteiro (planos seguintes, escritos depois que este estiver pronto):**
- Plano 2: Conteúdo KubeJS (itens customizados, moeda, receitas cruzadas, gates de dimensão/foguete/ProjectE, EMC).
- Plano 3: Lore + quests FTB (todos os capítulos, loot, loja) + validadores de quests (IDs/tags, dependências, alcançabilidade).
- Plano 4: Prompts GPT Image 2, integração das imagens (resource pack, FancyMenu, ícones), export final e guia de servidor.

## Global Constraints

- Minecraft **1.20.1**, Forge **47.x** (última estável 47.x), todos os mods na versão Forge 1.20.1.
- Servidor e testes de boot rodam com **Java 17**; nunca com o Java 21 do PATH.
- Mods só de cliente (`side = "client"`) nunca entram no pacote do servidor.
- Shaders **incluídos e desligados por padrão**; visuais pesados (Fresh Animations/EMF/ETF, Visuality, Sound Physics) **incluídos e desativados por padrão**.
- RAM: cliente **6 GB** recomendado; servidor **8–10 GB** (scripts usam `-Xmx10G -Xms4G`).
- Todo texto voltado ao jogador em **PT-BR**.
- Nome provisório do pack: **Ecos do Selo**; versão inicial `0.1.0`.
- ProjectE presente, mas **todas as receitas `projecte:*` removidas** até o Plano 2 definir os gates (o design trata como alquimia proibida, só no Ato V).
- Litematica: **Forgematica** (+ MaFgLib) se houver build 1.20.1 Forge; senão, Litematica Fabric via **Sinytra Connector** + Forgified Fabric API. Só no cliente.

## Review Focus

- **Mod só de cliente vazando para o servidor** → o servidor deve subir sem crash; `boot_test` do servidor pega isso (Task 4).
- **Java errado** (PATH aponta para o 21) → os scripts de start e o boot_test devem usar o Java 17 explicitamente; teste em Task 4.
- **Mod do CurseForge com download de terceiros bloqueado** → packwiz-installer falharia para os amigos; `check_manifest` deve marcar qualquer `.pw.toml` sem `url` de download (Task 2).
- **Shaders ou pack visual pesado ligados no primeiro launch** → PC fraco trava; teste de config em Task 5.
- **Dependência faltando ou versão incompatível** → crash no carregamento; boot de servidor (Task 4) e de cliente (Task 6) pegam isso.
